# 🌟 Гралик — ігри для малят 4–6 років

Шість простих ігор в одному додатку. Українською, з голосом, без реклами,
без інтернету і без жодного «програшу» — дитина не може зробити щось «не так».

**Грати:** https://genichka.github.io/gralyk/

---

## Ігри

| | Гра | Що розвиває |
|---|---|---|
| 🎵 | **Повтори мелодію** | слухову памʼять; послідовність росте з кожним колом |
| 🃏 | **Знайди пару** | зорову памʼять; від 3 до 8 пар |
| 🔢 | **Скільки?** | лічбу від 1 до 10 |
| 🔤 | **Перша буква** | українську абетку |
| 🐮 | **Хто як говорить** | звуки тварин на слух |
| 🐍 | **Змійка** | реакцію; повільна, без стін — не можна «врізатись» |

## Як це влаштовано для дитини

- **Великі кнопки**, нічого дрібного — пальчик не промахнеться.
- **Звуки тварин** синтезуються самою грою, не читаються синтезатором мови — тому «мууу» звучить як корова, а не як диктор.
- **Голос українською** читає завдання — але тільки справжнім українським голосом. Якщо його в телефоні немає, гра мовчить (чужий голос читає кирилицю своїми правилами і виходить «іноземець»). Як додати голос — написано в батьківському куточку.
- **Помилок не існує.** Неправильна відповідь — це мʼяке «спробуй ще», без втрати балів і без «Game over».
- **Зірочки ⭐** за кожне виконане завдання. П'ять зірочок — нова наліпка в альбом (усього 20).
- **Складність росте сама** — коли дитина впорається, наступне завдання трохи важче.

## Для батьків

Довге натискання (1,5 с) на назву вгорі екрана → приклад на додавання → налаштування:
увімкнути/вимкнути звуки і голос, подивитись скільки зібрано зірочок.

Приклад — щоб дитина випадково не зайшла в налаштування.

## Технічне

- Один файл `index.html` — уся гра всередині, без бібліотек і без жодного запиту в мережу.
- Звуки синтезуються через Web Audio API, аудіофайлів немає.
- PWA: можна додати на головний екран і грати в літаку (`sw.js` кешує оболонку).
- Прогрес (зірочки, наліпки, рекорд у змійці) зберігається в `localStorage` лише на цьому пристрої.

### Файли

```
index.html                 вся гра
manifest.webmanifest       щоб додавалась на головний екран
sw.js                      офлайн-кеш
icon-192.png
icon-512.png
icon-maskable-512.png
```

### Встановити на телефон

1. Відкрити посилання в Chrome (Android) або Safari (iPhone).
2. Меню браузера → **«Додати на головний екран»**.
3. Далі гра запускається як звичайний додаток, на весь екран і без інтернету.
